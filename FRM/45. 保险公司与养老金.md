# 保险公司概述

保险：一种经济补偿制度，通过对有可能发生的不确定性事件的数理预测和收取保险费的方法，建立保险基金，并且以合同的形式将风险从被保险人转移到保险公司，由大多数人来分担少数人的损失

## 保险合约的主体

**投保人(policyholder)**：向保险公司支付保险费(premiums)，保险公司则对合同中约定的可能发生的事故所造成的损失承担赔偿责任

**被保险人**：保险的承保对象

- 人寿保险中，被保险人和投保人往往是同一个人

**受益人(beneficiary)**：保险赔偿金的受领人

## 保险合约的分类

**人寿保险(life insurance)**：以被保险人的寿命为保险标的，以被保险人的生存或死亡为保险事故的人身保险

**财产与意外险((property-casualty insurance) / 损害保险**

- 广义：以财产及其有关的经济利益和投保人的损害赔偿责任为保险标的的保险
- 狭义：以物质财产为保险标的的保险

**健康险(health insurance) / 疾病保险**：以被保险人的身体为保险标的，针对被保险人在疾病或意外事故中所遭受的伤害或损失进行补偿的一种保险。

- 支付范围：医疗费用、收入损失、丧葬费及遗属生活费等

# 人寿保险

## 人寿保险的分类

**（一）根据保险期限分类**

**定期寿险(term life insurance) / 定期死亡保险**：当被保险人在保险合同有效期间发生死亡事故时由保险公司给付保险金的保险

- 如果保险期内被保险人生存，则无赔偿
- 适用情形：被保险人是家庭的主要经济来源

**终身寿险(whole life insurance)**：以投保人的死亡为给付保险金的条件，并且保险期限为终身的人寿保险

- 为投保人终生提供保险，投保人在其余生内每月或每年定期向保险公司支付保费，在投保人死后，保险公司向指定受益人提供赔偿
    - 通常为年金缴纳形式，即每年保费额相等
    - 死亡的概率随年龄的增大而增大，早期的预期盈余(expected surplus)会用于投资以支持后续的预期赤字(expected deficit)
- 给付是必然事件，保费比定期寿险稍高
- 优点：永久性保障、有退费的权利、可作为融资的抵押品

**储蓄寿险(endowment life insurance)**：有一定期限，但无论保险人在保险期限内死亡还是期满生存，都能获得给付的保险金

**（二）根据盈余保费分类**

**变额寿险(variable life insurance)**：一种固定缴费的产品，可以采用趸缴(即一次性缴清保费)或分期缴

- 与终身寿险的相同之处：均为终身保单，签发时都载明了保单面额
- 与终身寿险的不同之处
    - 变额寿险的盈余保费（surplus premium choice)由投资人投资，投资方式可以是股票基金、债券基金以及货币基金，投资报酬率无最低保证，现金价值不固定
    - 传统终身寿险的身故保险金固定，变额寿险身故保险金的给付受投资绩效的影响

**万能寿险(universal life insurance)**：投保人可以将保费减至不造成保险失效的某个最低水平，盈余保费被保险公司投资于固定收益产品，保险公司将担保最低回报率

- 在死亡发生时的最低给付是确定的
- 投保人可以缴纳最低保费，得到固定的给付
- 投保人也可选择支付更多的保费，给付金额可上浮

**变额万能寿险(variable-universal life insurance)**：融合保费缴纳灵活的万能寿险与投资灵活的变额寿险所形成的新险种

- 遵循万能寿险的保费缴纳方式：保单持有人可以根据自己的意愿将保额降至保单规定的最低水平，也可以在具备可保性时，将保额提高
- 投资通常是多种投资基金的集合
- 死亡给付与万能寿险相同，投资收益的变化只反映在保单现金价值中，而不改变保险给付金额

> 变额寿险、万能寿险和变额万能寿险都属于投资型保险，是人寿保险下面的分支，属于创新型寿险

**（三）根据被保险人分类**

**个人人寿保险(individual insurance)**：为满足个人和家庭需要，以个人作为承保单位的保险

**团体人寿保险(group insurance)**：以团体为对象，以团体的所有成员或者大部分成员为被保险人的人寿保险

## 生命表的应用

**（一）生命表**

**生命表(mortality table)**：保险公司依据特定人群的年龄组死亡率所编制出来的一种统计表

- 广泛应用于寿险产品定价、现金价值计算、准备金评估、内含价值计算、风险管理等各个方面
- 1693年，埃德蒙·哈雷首次编制，奠定了现代人寿保险的数理基础

**（二）保费的计算**

| 年龄 | 1年内死亡概率 | 生存概率 | 预期寿命 |
| ---- | ------------- | -------- | -------- |
| 30   |               |          |          |
| 31   |               |          |          |
| 32   |               |          |          |
| …    | …             | …        | …        |
| 72   |               |          |          |
| 73   |               |          |          |
| …    | …             | …        | …        |

**未来1年内死亡概率(probability of death within1 year)**：每一个年龄段的人在接下来1年内死亡的概率

**生存概率(survival probability)**：一个人活到$n$岁的累计概率

**第$n+1$年的生存概率**：通过第$n$​年的生存概率与未来1年内没有死亡的概率相乘得到
$$
第n+1年的生存概率=第n年的生存概率\times(1-未来1年内的死亡概率)
$$
**预期寿命(life expectancy)**：该年龄的人预期还能生存的年数。在计算时，往往假设一个人在年中死亡。

**保费的计算**：利用生命表以及寿险合约可计算出投保人的最低年缴保费金额

- 计算保单期限内，各年死亡的可能性
- 计算各年给付额的期望值的现值之和，用给定利率折现
- 设每年缴纳的保费为$X$，第一年保费发生在$t=0$时刻且缴纳概率为$100\%$；第二年保费发生在$t=1$时刻且缴纳概率为$(1-未来1年内的死亡概率)$；后续年份以此类推。计算各年期望保费的现值之和，用给定利率折现。
- 步骤2中的给付额的期望值的现值之和 = 步骤3中的期望保费的现值之和，可计算得出$X$

## 长寿风险与死亡风险

**长寿风险(longevity risk)**：个人或总体人群未来的平均实际寿命高于预期寿命产生的风险

- 来源：经济社会的发展、医学进步、生活方式转变、健康意识的提高
- 长寿风险会降低保险公司从年金合约中获取的利润(需要支付年金的时间拉长)，但会提高绝大多数人寿保险合约的利润(身故给付赔偿的时间推迟)

**死亡风险(mortality risk)**：个人或总体人群未来的平均实际寿命低于预期寿命产生的风险

- 来源：流行病、战争等
- 死亡风险会提高年金合约的利润(需要支付年金的时间缩短)，但会降低人寿保险的利润(身故给付赔偿的时间提前)

> 保险公司通常使用衍生产品或通过再保险的方式对长寿风险和死亡风险进行管理

# 年金合约

**年金合约(annuity contracts)**：将一次性的前期支付转化为后续一系列的现金流人，即年金

- 本质：保险公司代表投保人将前期的保费支付用于投资，后续将这些资产的回报用年金的形式返还给投保人
- 递延年金(deferred annuities)：从支付完成后递延数年之后开始支付
- 税务优势：税务的递延使投资以免税的方式增值，同时投保人缴纳的边际税率也更低
- 累计价值(accumulation value)：年金合约的投资总额

# 财产与意外险

**财产与意外险(property-casualty insurance)**

- **财产险(property insurance)**：对财物的意外损坏进行赔偿，如水险、火险。
- **意外险(casualty insurance)**：对由于被保险人的行为而造成的对他人伤害或损害的责任承保
- 通常将财产险和意外险合并为一张保险合同进行出售
- 财产与意外险合约通常期限为1年，到期投保人可选择是否继续投保，保费会随投保人的风险进行调整

## 各类风险

- 由于许多相互独立的投保人索赔，导致根据历史数据可合理估计的保费增加的风险
- 巨灾风险(catastrophe risks)：某个单一事件(龙卷风或地震)可同时引起众多赔偿要求的风险

## 巨灾风险的管理

**再保险(reinsurance)**：保险公司在原保险合同的基础上，通过签订分保合同，将其所承保的部分风险和责任向其他保险公司(又称再保险公司)进行保险的行为

**巨灾债券(catastrophe bond，CAT)**：衍生工具，由保险公司发行，未来债券本金及债息的偿还与否，完全根据巨灾损失发生情况而定

- 如果在约定期限内指定的承保损失超过一定限额，债券投资人的本金和票息收益将用于弥补保险公司超过限额的承保损失；若指定的承保风险损失没超过该限额，则债券投资者可得到高于无风险利率的票息回报，作为承担相应承保风险的补偿
- 巨灾债券的本金金额：取决于债券的结构、保险需求和市场需求，会根据具体的债券设计有所不同
- 票息的高低：取决于市场对该风险的定价和评估，并非直接由本金的高低决定

## 业绩评估

**赔付率(loss ratio)**：赔付支出(payouts)占保费收入(premiums earned）的比例
$$
赔付率=\dfrac{赔付支出}{保费收入}\times 100\%
$$

- 赔付率越低，保险公司效益越好

**保费费用率(expense ratio)**：全部费用(total expense)占保费收入的比例
$$
保费费用率 = \dfrac{理赔费用+销售费用}{保费收入}\times 100\%
$$
**综合费用率(combined ratio)**：赔付率与保费费用率之和
$$
综合费用率 = 赔付率 + 保费费用率 = \dfrac{赔付支出+理赔费用+销售费用}{保费收入}\times 100\%
$$

- 反映保险企业经营管理状况的非常重要的效益指标

**分红后的综合费用率(combined ratio after dividend)**
$$
分红后的综合费用率 = 综合费用率 + 分行(\%)
$$
**运营费用率(operating ratio)**：分红后的综合费用率减去投资收益率
$$
运营费用率 = 分红后的综合费用率 - 投资收益率
$$

- 是衡量成本的指标，反映保险公司的毛利润情况(gross profitability)

# 健康险

**健康险(health insurance)**：以被保险人的身体为保险标的，针对被保险人在疾病或意外事故中所遭受的伤害或损失进行补偿的一种保险

- 保费会根据具体情况而变化
- 健康险的保费一般会随医疗费用升高而增加，但如果投保人患上了保单签订时没有预测到的疾病，则保费不能提高
- 赔付具有变动性和不可预测性

# 道德风险与逆向选择

**道德风险(moral hazard)**：个人在风险得到保障之后改变日常行为的一种倾向

- 事前道德风险：投保人得到保险保障后就丧失了预防损失的动力
- 事后道德风险：损失发生后，投保人丧失减少损失、减轻损失程度的动力
- 管理策略：采用免赔额(deductible)、共同保险条款(co-insurance provision)、保单限额(policy limit)

**逆向选择(adverse selecion)**：因投保人掌握的自身信息多于保险公司，可能导致高风险的个体倾向于购买更多保险，而低风险个体则可能不购买保险

- 可能的后果
    - 难以准确甄别投保人的真实风险水平，导致既定的定价策略失效
    - 导致原有的保险价格吸引更多高风险投保人，进而提高了保险公司潜在的赔付水平
- 管理策略：尽可能获取投保人的详细信息，采用差异化定价、健康检查等方式识别投保人风险水平；引入再保险等机制

# 保险投资

最主要的投资工具为长期债券，包括公司长期债券和政府长期债券

- 相对于股票来讲，债券作为固定收益产品的风险更低
- 长期债券的期限可以帮助完成期限匹配策略（资产负债管理策略(asset-liability management，ALM)）

# 保险业监管

保险公司蕴含多种风险

- 资产端：由于投资于长期债券，面临市场风险、信用风险和利率风险等
- 负债端：面临与赔偿给付相关的长寿风险和死亡风险
- 存在操作风险

## 资本金要求

Solvency II 对在欧盟国家经营的保险公司确了**最低资本金要求(minimum capital requirement，MCR)和偿付资本金要求(solvency capital requirement，SCR)**

- 计算可采用标准法和内部模型法，但内部模型法需要被各国的金融监管机构批准
    - 资本金计算会考虑投资风险（资产端）、承保风险（负债端）与操作风险
- 资本金低于SCR，则需要将资本金补足到SCR水平
- 资本金低于MCR，则不允许继续发展新业务，现有业务也会被转移给其他保险公司
- MCR一般为SCR的25%-45%

## 监管体系（美国）

- 保险业以州作为单位进行管理
- 美国保险管理委员会(National Association of Insurance Commissioners，NAIC)作为全国的协会，负责为各个州的监管主体提供相关数据和意见
- 缺乏一个持续的基金为投保人提供保护，保险公司的偿付问题各州自行解决

# 养老金计划概述

**养老金计划(pension plan)**：企业和职工之间签订的关于退休后支付养老金的协议

## 缴纳确定型养老金

**缴纳确定型养老金(defined contribution pension plan，DC pension plan) / 设定提存计划 / DC型养老金**：一个企业与其职工之间签订合同，按合同规定职工和公司共同出资，以固定比例的工资向养老金账户定期存人资金，并进行投资

- 最终养老金的数额取决于所缴纳的养老金数额及其投资收益
- 养老金相关风险完全由职工个人承担，企业仅仅是共同缴纳者和中介

## 收益确定型养老金

**收益确定型养老金(defined benefit pension plan，DB pension plan) / 设定收益计划 / DB型养老金**：雇主在员工退休之后，有义务定期向退休人员支付固定金额的养老金

- 退休人员可选择一次性拿走全部养老金，也可以采用年金的方式收取
- 养老金水平和员工退休前的工资水平、工作年限等有关
- 企业通过精算师来计量未来负债的现值，并与当前计划中资产的价值相比
    - 如果资产价值小于未来负债的现值，不足的部分将由雇主来补足
    - 会计法规定计算现值使用的折现率应为AA级别债券的回报率
- 往往将大多数资金投资于股票市场以支撑未来的给付
