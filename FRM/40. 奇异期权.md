# 奇异期权的含义

奇异期权（新型期权）：回报取决于各种独特的条款，可以满足投资者独特需求并通常在OTC市场进行交易的期权

- 分类：单一资产期权、多个资产期权

# 资产期权

## 路径依赖性期权

- 报酬与期权存续期间的标的物价格走势有关
- 包含：亚式期权、障碍期权、回顾期权、棘轮期权

**（一）亚式期权**

亚式期权(Asian options)：收益依赖于标的资产价格的某种平均值的期权

- 根据平均值类型不同

    - 一段时间内的连续平均值、若干个时间点的离散平均值

    - 算术平均亚式期权（较为常见）、几何平均亚式期权

- 根据结算方式不同

    - 平当价格期权（固定执行价格的亚式期权）：以有效期内标的资产在某段时间的平均价格$(S_{avg})$来代替欧式期权中到期日标的资产价格
        - 看涨期权的收益为$\max(0,S_{avg}-X)$，看跌期权的收益为$\max(0,X-S_{avg})$
    - 平价执行价格期权（浮动执行价格的亚式期权）：期权有效期内标的资产某段时间内的平均价格作为执行价格的期权
        - 看涨期权的收益为$\max(0,S_{T}-S_{avg})$，看跌期权的收益为$\max(0,S_{avg}-S_{T})$
    - 平均价格期权比平均执行价格期权更为普遍

- 亚式期权的权利金总是低于标准期权的权利金：标的资产平均价格的波动率总是小于标的资产单个价格的波动率

**（二）障碍期权**

障碍期权(barrier options)：收益取决于资产是否达到特定的障碍水平

- 敲出障碍期权(knock-out options)：当标的资产价格达到一个特定的障碍水平时，该期权作废(即被“敲出”)，否则为常规期权
    - 向上敲出期权(up-and-out)：在期权到期前，标的资产价格升高并高于障碍水平时，该期权作废
    - 向下敲出期权(down-and-out)：在期权到期前，标的资产价格降低并低于障碍水平时，该期权作废
- 敲入障碍期权(knock-in options)：只有资产价格在规定时间内达到障碍水平，该期权才得以存在(即被“敲入”)，否则该期权作废
    - 向上敲入期权(up-and-in)：在期权到期前，标的资产价格升高并高于障碍水平时，该期权生效
    - 向下敲入期权(down-and-in)：在期权到期前，标的资产价格降低并低于障碍水平时，该期权生效
- 特点：价格相对较便宜、收益非连续、期权不随着标的资产价格波动性增加而价值增加

**（三）回顾期权**

回顾期权(lookback options)：一种特殊的欧式期权，它的收益取决于有效期内标的资产曾经达到过的最高价格或最低价格

- 浮动回顾看涨期权（执行价格的浮动）：等价于资产在最低价位买入，损益为$\max(0,S_T-S_{\min})$
- 浮动回顾看跌期权：等价于资产在最高价卖出，损益为$\max(0,S_{\max}-S_T)$
- 固定回顾看涨期权（执行价格固定）：等价于资产在最高价位卖出，损益为$\max(0,S_{\max}-X)$
- 固定回顾看跌期权：等价于资产在最低价买入，损益为$\max(0,X-S_{\min})$
- 特点：回顾期权比标准期权更加昂贵，价值与价格观察频率正相关

**（四）阶梯期权**

阶梯期权(cliquet options) / 棘轮期权：一系列远期期权（foward start options）组成的一种奇异期权

- 第一个期权立刻生效，第二个期权在第一个期权到期后再生效。每个期权的执行价格会按照约定日期的价格重新设置

## 时间依赖性期权

- 报酬与时间及当时标的资价格有关
- 包括：非标准化美式期权、任选期权、远期生效期权

**（一）非标准化美式期权**

非标准化美式期权(non-slandard American options) / 百慕大期权(Bermuda options)

- 只能在期权有效期的某些特定日期可提前执行，而不是在期权有效期内的任一营业日都可提前执行
- 存在锁定期(lock-out period)，该时间段内不能行权
- 在不同时间执行会有不同的执行价格

**（二）任选期权**

任选期权(chooser options)：持有者可在期权有效期内的某一时点选择该期权为看涨期权或看跌期权

- 在选择点$T_1$，期权价值为看涨和看跌期权价值孰大
- 任选期权的期权费一般较高，购买者具有更大的选择权

**（三）远期生效期权**

远期生效期权（forward start options）/ 未来生效期权：买方在期初支付权利金，并在未来某一时期后，期权才生效，其执行价格即为期权启动时刻标的资产的价格，是一种与时间相关的期权

- 雇员股票期权可被视为一种远期生效期权

## 其他类型期权

**（一）打包期权**

打包期权(packages)：由标准欧式看涨期权、标准欧式看跌期权、远期合约、现金及标的资产本身构成的组合

- 各类差价期权和组合期权都属于打包期权，反映了投资者关于市场的某些观点以及风险承受度。

**（二）零成本产品**

零成本产品（zero-cost products）：不需要初始投资。

假设某衍生品的初始投资为$f$，$T$ 时刻到期，转化为零成本产品的方式

- 将初始投资 $f$ 推延至 $T$ 时刻，支付$f(1+R)^T$
    - 假设欧式看涨期权的正常期权费为$c_0$，其对应零成本产品的损益为$\max(-c_0(1+R)^T,S_T-X-c_0(1+R)^T)$
- 将期权转化为期货产品，即期货式期权(futures style options)
    - 在交易所进行交易并采用逐日盯市制度

**（三）缺口期权**

缺口期权(gap options)：一种欧式期权，其触发收益的价格与计算收益的执行价格不同。

假设触发价格为$X_2$，用于计算收益的执行价格为$X_1$

- 看涨期权，若$S_T>X_2$，则其损益为$C_T=S_T-X_1$
- 看跌期权，若$S_T\leq X_2$，则其损益为$C_T=X_1-S_T$

**（四）复合期权**

复合期权(compound options）：以期权合约作为标的资产的期权合约，是期权的期权

- 看涨期权为标的资产的看涨期权（call option on call option）：给予购买者在$T_1$时刻支付$X_1$来做多一个执行价格为$X_2$且在$T_2$到期的看涨期权
- 看涨期权为标的资产的看跌期权（put option on call option）：给予购买者在$T_1$时刻收到$X_1$来做空一个执行价格为$X_2$且在$T_2$到期的看涨期权
- 看跌期权为标的资产的看涨期权（call option on put option）：给予购买者在$T_1$时刻支付$X_1$来做多一个执行价格为$X_2$且在$T_2$到期的看跌期权
- 看跌期权为标的资产的看跌期权（put option on put option）：给予购买者在$T_1$时刻收到$X_1$来做空一个执行价格为$X_2$且在$T_2$到期的看跌期权

**（五）两值期权**

两值期权(binary options)：是一种具有不连续收益的期权。

- 现金或无价值看涨期权(cash-or-nothing call)：在到期时，若标的资产价格低于执行价格，则该期权一文不值，而当标的资产价格高于执行价格时该期权支付一个固定数额
- 现金或无价值看跌期权(cash-or-nothing put)：在到期时，若标的资产价格高于执行价格，则该期权一文不值，而当标的资产价格低于执行价格时该期权支付一个固定数额
- 资产或无价值看涨期权(asset-or-nothing call)：在到期时，若标的资产价格低于执行价格，则该期权一文不值，而当标的资产价格高于执行价格时，该期权支付一笔等于资产本身价值的款额
- 资产或无价值看跌期权(asset-or-nothing put)：在到期时，若标的资产价格高于执行价格，则该期权一文不值，而当标的资产价格低于执行价格时，该期权支付一笔等于资产本身价值的款额

传统的欧式期权可利用两值期权来构建

- 欧式看涨期权的多头：做多资产或无价值看涨期权+做空现金或无价值看涨期权，其中现金或无价值看涨期权的收益为执行价格
- 欧式看跌期权的多头：做多资产或无价值看跌期权+做空现金或无价值看跌期权，其中现金或无价值看跌期权的收益为执行价格

两值期权的不连续收益会滋生更多的价格操纵，在一些国家被禁止交易

# 多个资产期权
## 资产交换期权

资产交换期权（asset-exchange options）：选择权买方有权利以某种资产交换另一种资产（外汇、股票等）

- 买方：持有标的资产的同时，持有一个将该资产转换为其他资产的权利

## 篮子期权

篮子期权(basket options)：标的资产为几种资产构成的资产组合的期权

- 价值取决于资产组合中各资产的多元波动率结构与资产的相关系数

# 基于波动性的互换

该类期权通过先计算资产每日回报率的标准差得到每日波动性，再将每日波动性乘以$\sqrt{252}$得到年化波动性

## 波动率互换

波动率互换(volatility swap)：标的为资产波动性的互换合约，以事先约定好的波动性和合约期间实际的波动性作为计算互换现金流的基础

- 支付固定方：波动率互换的收益为$L_{vol}(\sigma-\sigma_K)$
- 收取固定方：波动率互换的收益为$L_{vol}(\sigma_K-\sigma)$

$L_{vol}$：交换的名义本金，$\sigma$：互换合约期间对波动率进行年化后的结果，$\sigma_K$：事先约定好的年化波动率

## 方差互换

方差互换(variance swap)：标的为资产波动的方差

- 支付固定方：波动率互换的收益为$L_{vol}(\sigma^2-\sigma^2_K)$
- 收取固定方：波动率互换的收益为$L_{vol}(\sigma^2_K-\sigma^2)$

$L_{vol}$：交换的名义本金，$\sigma$：互换合约期间对进行年化后的结果，$\sigma_K$：事先约定好的年化波动率

# 静态期权复制策略

- 一些奇异期权比较容易被对冲：亚式期权的价值对于资产价变动的敏感度更低，回报更容易预测
- 一些奇异期权较难被对冲：降碍期权。静态期权复制（static options replication）的对冲方式较为常用

障碍期权风险对冲

- 难点：其敲出边界的收益是不连续的
- 方法：构建一个期权组合，满足收益与障碍期权在敲出边界处的收益相同的条件，当投资着买入了障碍期权的时候，只要同时卖出事先构建的期权组合就可以对冲掉敲出边界的风险
